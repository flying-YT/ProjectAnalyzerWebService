制限事項・対応ファイル形式について

アップロードの上限

  • アップロードできるのは .zip ファイルのみです。
  • ZIPファイルのサイズ: 最大100MB
  • 展開後の合計サイズ: 最大500MB
  • ZIP内のファイル数: 最大10,000件

⚠️ パスワード付きファイルは解析できません

  • 暗号化ZIP（パスワード付きZIP）は展開できず、解析がエラーになります。パスワードを解除してからアップロードしてください。
  • ZIP内の読み取りパスワード付きOfficeファイル（Excel / Word / PowerPoint）は開けないため、そのファイルだけスキップされて出力に含まれません。
  • 「読み取り専用推奨」や書き込みパスワードのみのファイルは、通常どおり解析できます。

内容を構造化して抽出できる形式

  • Excel: .xlsx .xlsm .xls（シート単位。図形・テキストボックスは .xlsx .xlsm のみ）
  • Word: .docx（表はMarkdownのテーブルに変換されます）
  • PowerPoint: .pptx（スライド単位）
  • テキスト全般: ソースコード、.md、.json、.xml、.csv などのテキストファイル

処理対象外のファイル形式

  • 旧形式のOffice: .doc .ppt（.xls のみ対応）
  • PDF: .pdf は非対応です。
  • 単体の画像ファイル: .png .jpg .gif などはOCRの対象外です（OCRはOfficeファイルに埋め込まれた画像のみ対象）。
  • その他のバイナリ: 実行ファイル、動画、音声、圧縮ファイル、フォントなど。

これらは内容を解釈できずテキストとして読み込まれ、出力が文字化けして無意味に肥大化します。アップロード前にZIPから除外することを強く推奨します。

自動的に除外されるフォルダ

  • bin / obj / .vs / .git は既定で除外されます。
  • プロジェクト直下に .projectanalyzerignore を置くと、1行に1つずつ除外対象（例: node_modules）を追加指定できます。

その他

  • ZIP内のファイル名は Shift_JIS / UTF-8 を自動判定するため、Windows・macOSどちらで作成したZIPも利用できます。
  • アップロードされたファイルと解析結果はサーバー上の一時領域で処理され、ダウンロード完了後に自動的に削除されます。
  • OCRを有効にすると処理時間が大幅に伸びます。大きなプロジェクトではタイムアウトすることがあります。
